    **ReportsController optimizations:**

    **GetEventPerformanceReport(int eventId):**
    - Currently loads all requests with User AND Votes (two collection Includes)
    - Convert to projection:
      ```csharp
      var eventInfo = await _context.Events
          .AsNoTracking()
          .Where(e => e.EventId == eventId && e.DjUserId == djUserId)
          .Select(e => new { e.EventId, e.Name, e.Slug, e.IsActive })
          .FirstOrDefaultAsync();
      if (eventInfo == null) return NotFound("Event not found or access denied");

      var reportRows = await _context.Requests
          .AsNoTracking()
          .Where(r => r.EventId == eventId)
          .OrderByDescending(r => r.Votes.Count)
          .ThenBy(r => r.CreatedAt)
          .Select(r => new EventPerformanceReportRowDto
          {
              SongName = r.SongName,
              ArtistName = r.ArtistName,
              Requester = r.User.Username,
              VoteCount = r.Votes.Count,
              Status = r.Status.ToString(),
              RequestedAt = r.CreatedAt,
              StatusUpdatedAt = r.Status != RequestStatus.Pending ? (DateTime?)DateTime.UtcNow : null
          })
          .ToListAsync();
      ```
      Summary statistics can then be computed from the projected reportRows in-memory (they're already flat DTOs).

    **GetDjAnalyticsReport():**
    - Currently loads ALL events with ALL requests with ALL votes - extremely expensive
    - Convert to projection:
      ```csharp
      var reportRows = await _context.Events
          .AsNoTracking()
          .Where(e => e.DjUserId == djUserId)
          .Select(e => new DjAnalyticsReportRowDto
          {
              EventName = e.Name,
              EventSlug = e.Slug,
              EventDate = e.CreatedAt,
              TotalRequests = e.Requests.Count,
              ApprovedRequests = e.Requests.Count(r => r.Status == RequestStatus.Approved),
              RejectedRequests = e.Requests.Count(r => r.Status == RequestStatus.Rejected),
              TotalVotes = e.Requests.SelectMany(r => r.Votes).Count(),
              UniqueParticipants = e.Requests.Select(r => r.UserId).Distinct().Count(),
              IsActive = e.IsActive
          })
          .OrderByDescending(r => r.EventDate)
          .ToListAsync();
      ```
      Summary can be computed from reportRows in-memory.
